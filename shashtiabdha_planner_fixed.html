🚀 Deploy to GitHub Pages — Free Hosting (Always Available)

Host this planner online so anyone can open it from any device via a URL. GitHub Pages is completely free.

OPTION A — GITHUB PAGES (FREE, PERMANENT URL)
Step 1 — Create a GitHub account
Go to github.com → Sign Up (free). Use your Gmail.

Step 2 — Create a new repository
Click the + icon → New Repository → Name it: shashtiabdha-planner → set to Public → Create.

Step 3 — Upload this HTML file
In your new repo → click Add file → Upload files → drag & drop this HTML file → rename it to index.html → click Commit changes.

Step 4 — Enable GitHub Pages
In the repo → Settings → Pages → Source: Deploy from a branch → Branch: main → folder: / (root) → Save.

Step 5 — Get your URL
After ~1 minute, your site is live at:
https://YOUR-GITHUB-USERNAME.github.io/shashtiabdha-planner/

Share this URL with family. Open on iPhone, Android, Windows — works everywhere.

To update the site later: Go to the repo → click index.html → pencil icon → paste new version → Commit. Updated in ~1 min.
OPTION B — NETLIFY DROP (EVEN SIMPLER, 30 SECONDS)
1. Go to netlify.com/drop
2. Drag and drop this HTML file onto the page
3. You instantly get a URL like https://random-name-123.netlify.app
4. Share that URL with family

🏗️ Technical Architecture

Pattern: Single-file PWA · LocalStorage (offline-first) · Optional Supabase cloud sync
Data flow: Every write → localStorage immediately (instant, offline) → Supabase REST API in background (if configured)
On startup: If Supabase configured → fetch all tables → merge into localStorage → render
Scalability path: Phase 1: localStorage only → Phase 2: Supabase sync → Phase 3: Multi-user with RLS → Phase 4: React Native app
Works on: iPhone Safari, Android Chrome, Windows Chrome/Edge/Firefox
Tables: tasks, guests, schedule, shopping, budget, brahmanas (all in Supabase PostgreSQL)
API: Supabase PostgREST — GET/POST/PATCH/DELETE per table
